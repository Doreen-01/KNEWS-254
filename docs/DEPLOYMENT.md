# KNEWS254 DIGITAL MEDIA NETWORK - DEPLOYMENT GUIDE

## Application Architecture

- **Frontend Framework**: React 19 with Vite & TypeScript
- **Styling**: Tailwind CSS with custom typography & layout
- **Backend Entrypoint**: Express server (`server.ts`)
- **Database & Storage**: Supabase (Cloud PostgreSQL + Object Storage)
- **AI Engine**: Google GenAI SDK (`@google/genai`)

---

## Production Build & Run Commands

```bash
# Install dependencies from the committed lockfile
pnpm install --frozen-lockfile

# Type-check, build the client SPA, and compile the backend server
pnpm run lint
pnpm run build

# Launch the production server; the platform-provided PORT is honored
NODE_ENV=production PORT=8080 pnpm run start
```

---

## Server Binding & Reverse Proxy Requirements

- **Port**: The platform-provided `PORT` value, defaulting to `3000` locally and `8080` in the container.
- **Host**: `0.0.0.0`
- **Container**: Build with the included `Dockerfile`; Cloud Run or another container platform may provide the runtime port.

---

## SEO & Indexing Infrastructure

- **Liveness**: `GET /api/health` returns 200 when the server is running.
- **Readiness**: `GET /api/ready` returns 200 when the Supabase client configuration is present, otherwise 503 with a safe diagnostic.
- **Dynamic Sitemap**: Available live at `/sitemap.xml` and `/api/sitemap.xml`
- **RSS Feed**: Available live at `/rss.xml` and `/api/rss.xml`
- **Structured Data**: Automatic JSON-LD schemas generated by `<SeoManager />` for Articles (`NewsArticle`), Categories (`CollectionPage`), and WebSite.
